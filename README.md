# bi-analytics-portfolio
Портфолио аналитических проектов Яндекс Практикума
Разработка BI-дашборда для агентства недвижимости — декомпозировал аналитическую задачу, провел первичный анализ и предобработку данных в DBeaver с помощью SQL-запросов; построил интерактивный дашборд в Yandex DataLens с гибкой системой фильтрации и детализацией по дням, неделям, месяцам и годам для отслеживания динамики цен и продаж.
